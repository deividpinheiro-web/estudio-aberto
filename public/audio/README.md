# Trechos de áudio

Coloque aqui os trechos (MP3) liberados pelos artistas, por exemplo:

- veigh.mp3
- nandatsunami.mp3
- sotam.mp3
- 22diniz.mp3

Depois, em `src/data.js`, troque o campo `audio` de cada artista:

    audio: "audio/veigh.mp3"

Use só arquivos que o grupo tem autorização para publicar.
